How to read these results

The report compares the same generated records and query workload in EFS_FULL and PLAINTEXT_CONTROL modes. It includes throughput, warm latency percentiles, correctness, failures and timeouts, indexing rate, relation sizes, JVM/runtime, PostgreSQL, host, and workload metadata.

Measurements are informational. No latency, throughput, or encryption-overhead threshold has been approved. A single run can vary with runner scheduling, JVM behavior, and database state; compare repeated runs before drawing conclusions.
